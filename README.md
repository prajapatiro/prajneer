# PRAJNEER Multi-Page Website

This package contains separate HTML pages for each main website section.

## Pages
- `index.html` — Home
- `services.html` — RO Services
- `brands.html` — RO Brands
- `new-ro.html` — New RO enquiries
- `why-prajneer.html` — Why PRAJNEER
- `service-areas.html` — Gurugram service areas
- `reviews.html` — Reviews information
- `faqs.html` — FAQs
- `contact.html` — Contact and booking form

## Run locally
Open `index.html` in a web browser. Use the navigation to move between pages. The logo and hero technician image are embedded in the HTML, so separate image files are not required.

## Before publishing
Replace any remaining `prajneer.example` canonical/schema URLs with the real domain. Review business address, opening hours, service claims and structured data for accuracy. For production SEO, provide `robots.txt` and `sitemap.xml` at the website root.
